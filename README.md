# STM32F411RE — Embedded Systems

Repositorio de proyectos de firmware desarrollados con
STM32CubeIDE y la tarjeta NUCLEO-F411RE.

## Objetivo

Desarrollar habilidades de programacion embebida en C,
configuracion de perifericos, depuracion y acceso a registros.

## Hardware y herramientas

- STM32 NUCLEO-F411RE
- Microcontrolador STM32F411RET6
- STM32CubeIDE
- STM32CubeMX
- ST-LINK
- C, HAL y CMSIS
